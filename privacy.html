Privacy Policy / 隐私权政策

Mail Master · Last updated / 最后更新：2026-11-17

Who uses this app / 谁在使用

Mail Master is a personal tool used only by its owner on the owner's own home server. It is not offered to the public.

Mail Master 是作者个人自用的工具，只运行在作者自己的家庭服务器上，不对外提供服务。

Data accessed / 访问哪些数据

With the owner's permission (Google OAuth scope https://mail.google.com/), the app reads the owner's Gmail messages, folders/labels and flags over IMAP.

经作者本人授权（Google OAuth 范围 https://mail.google.com/），通过 IMAP 读取作者本人 Gmail 的邮件、文件夹 / 标签和已读、星标状态。

How data is used / 如何使用

  • To build a search index and show the owner's mail to the owner. / 建立检索索引，把邮件显示给作者本人看。
  • To mark as read, star, move or delete mail only when the owner does so in the app. / 只在作者本人操作时标已读、加星标、移动或删除邮件。
  • The app never sends mail. / 本工具不发送邮件。

Storage and sharing / 存储与共享

  • Mail data and OAuth tokens are stored only on the owner's own server, in files readable only by the owner. / 邮件数据和授权令牌只保存在作者自己的服务器上，文件只有作者能读。
  • No data is sold, shared with or transferred to any third party, and none is used for advertising or to train AI models. / 不出售、不共享、不转交给任何第三方，不用于广告，也不用于训练 AI 模型。

Google API Services User Data Policy

Mail Master's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access / 撤销授权

Access can be revoked at any time at myaccount.google.com/permissions. The owner can delete the local data at any time.

随时可以在 myaccount.google.com/permissions 撤销授权；本地数据作者可随时删除。
