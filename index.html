Mail Master

Mail Master is a personal, self-hosted mail search tool. It runs only on the owner's home server (NAS) and is used only by its owner to search and organize the owner's own mailboxes.

Mail Master 是个人自用的邮件检索工具，只运行在作者自己家里的服务器（NAS）上，只用来检索、整理作者本人的邮箱。

What it does / 功能

  • Signs in to the owner's Gmail account with Google OAuth and reads mail over IMAP to build a local search index. / 用 Google 授权登录作者本人的 Gmail，通过 IMAP 读取邮件，在本地建立检索索引。
  • Marks mail as read, stars, moves or deletes mail only when the owner does so in the app. / 只有作者在界面里操作时，才标已读、加星标、移动或删除邮件。
  • It never sends mail. / 不发送任何邮件。
